Procedure de vote en ligne

ÉTAPE 1 : INSCRIPTION

Connectez-vous sur le site de vote numérique : la procédure d'inscription sur les listes électorales est la suivante :

  1. Cliquez sur le lien « Inscription ».
  2. Un formulaire d'inscription vous est présenté.
  3. Remplissez soigneusement le formulaire en lisant avec précaution les informations demandées.
  4. Après avoir fini de remplir les champs du formulaire, vérifiez que vos informations sont correctes.
  5. Validez votre inscription en cliquant sur le bouton « Soumettre » situé en dessous du formulaire, ou cliquez sur « Annuler » pour effacer les informations renseignées.
  6. Vérifiez que vous avez reçu votre code d'identification unique et votre nom d'utilisateur.

ÉTAPE 2 : CONNEXION À VOTRE COMPTE

Pour accéder à votre compte personnel, suivez les étapes suivantes :

NB : les informations demandées doivent être identiques à celles attribuées lors de l'inscription.

  • 1 - Cliquez sur le bouton « Connexion ».
  • 2 - Entrez le code d'identification unique qui vous a été attribué lors de l'inscription sur la liste électorale pour confirmer votre identité.
  • 3 - Entrez votre nom d'utilisateur.
  • 4 - Appuyez sur « OK » pour valider.

    • Si vous rencontrez des problèmes, veuillez contacter notre personnel technique.

ÉTAPE 3 : VOTE

CLIQUER SUR LE LIEN « VOTER » ET SUIVEZ LES ÉTAPES SUIVANTES :

    • 1 - Entrez votre code d'identification unique et votre nom d'utilisateur.
    • 2 - Choisissez le type d'élection auquel vous souhaitez participer.
    • 3 - Sélectionnez le candidat pour lequel vous voulez voter.
    • 4 - Ensuite, cliquez sur « Voter ».
    • 5 - Un pop-up doit s'afficher et vous présenter le candidat choisi et ses informations afin de vous permettre de vérifier votre choix.
    • 6 - Si le choix est valide, cliquez sur « OK ».
    • 7 - Vous recevrez un quitus de confirmation pour votre vote.
    • 8 - Votre vote est désormais validé de façon anonyme et sécurisée.
CONDITIONS D'ÉLIGIBILITÉ AUX ÉLECTIONS

ÉLECTION PRÉSIDENTIELLE

Pour être éligible à la présidentielle, un candidat doit :
    • Âge : avoir au moins 35 ans.
    • Nationalité : posséder la nationalité du pays dans lequel il souhaite se présenter.
    • Droits : jouir de ses droits civiques et politiques.
    • Présentation : être présenté par un parti politique légalement reconnu.
    • Résidence : justifier d'une résidence continue d'au moins 12 mois dans le pays.
    • Inscription : être inscrit sur les listes électorales.
    • Caution : s'acquitter de la caution demandée pour les dossiers de candidature.

ÉLECTIONS LÉGISLATIVES

Pour être éligible aux élections législatives, le candidat doit :
  • Nationalité : être de nationalité camerounaise.
  • Âge : avoir au moins 18 ans pour être candidat.
  • Cautionnement : payer le cautionnement requis pour se présenter.
  • Droits : jouir de ses droits civils et politiques.

ÉLECTIONS RÉGIONALES

Pour être éligible aux élections régionales, le candidat doit :
  • Nationalité : être de la nationalité du pays dans lequel il souhaite postuler.
  • Âge : être majeur (18 ans au moins).
  • Résidence : aucune résidence spécifique n'est généralement requise, mais l'éligibilité dépend du respect des autres conditions.
